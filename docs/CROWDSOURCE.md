# CROWDSOURCE — Voices + Content

To stay free + NCTB-accurate, we crowdsource:

1. **Letters dataset:** add entries in `packages/ai-engine/src/sworoborna.js` (letter, word, emoji, tts). One PR per letter = easy star!
2. **Voices:** record `অ-ঔ, ক-...` MP3s (44.1kHz, noise-free). Future: `public/audio/<letter>.mp3` with fallback to speechSynthesis.
3. **Quizzes:** Tier 2/3 in `docs/` proposals, must cite NCTB book/page.
4. **Leaderboard:** top contributors get `dashboard_reward` badge + README credits.

Quality gate: native speaker review + schema validator + kid-test video.
